Reverse_engineering Hardware

Have you ever thought how USB data blockers actually made? I surely did, that why I teared one by myself.

What does USB data blocker do?

Well… I guess you can guess it from the name - it really just block data transfer between connected hosts. Nothing more. Fancy, right?

But why someone can need this function? The answer is pretty simple, if you ever was interested in cybersecurity just a little: there’s a special attack named “Bad USB” that utilizes USB connection to send keystrokes (and execute code in result).
